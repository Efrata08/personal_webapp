# efratabogale.vercel.app

Personal site and portfolio.

**Live:** https://efratabogale.vercel.app

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Vercel

## Running locally

```bash
git clone https://github.com/Efrata08/personal_webapp.git
cd personal_webapp
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

```
app/          # routes and pages
components/   # reusable UI
public/       # static assets
```
